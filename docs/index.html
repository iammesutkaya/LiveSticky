What is LiveSticky?

LiveSticky handles your entire stream lifecycle on Reddit automatically. Go live on Twitch, YouTube, or Kick and it pins a fresh post, keeps an interactive dashboard updated in real-time, and archives everything with a highlights post when you wrap.

The standout is the multistream dashboard — a live custom post that surfaces every platform you're broadcasting on side by side, so your community never has to guess where to watch.

Built on the Reddit Developer Platform (Devvit) and fully open-source - inspect the code, follow updates, and report issues on the GitHub Repository.

✨ Core Features

🔴

Automatic Live Posts

Checks Twitch, YouTube, and Kick every 2 minutes and pins a new post the moment you go live — on any platform, no manual action needed.

⚡

Real-Time Statistics

Keeps the live post body up-to-date with current viewer count, uptime, and current game or category like Just Chatting.

🛡️

Crash Grace Period

Waits 6 minutes before concluding — so a brief OBS restart or Twitch hiccup won't spam your community with duplicate posts.

📺

Multistream Aware

Tracks Twitch, YouTube, and Kick together — the dashboard shows every platform you're live on so viewers pick where to watch.

🏁

Concluding VOD Archives

When the stream ends, LiveSticky edits the post to an offline archive state with VOD links, locks it, and unpins it automatically.

🎥

Stream Highlights Post

Queries the Twitch Clips API on stream end to compile the top 5 clips into a standalone highlights post for your community.

📌

Pinned Mod Comment

Auto-posts a customizable, pinned moderator comment — great for Discord links, community rules, or social callouts.

🏷️

Custom Post Flair

Applies your community's custom post flair template to the live post automatically — e.g., "🔴 Live Now".

📊

Sidebar Widget

Keeps a "STREAM STATUS" sidebar widget updated in real-time with live/offline state, category, viewers, and uptime.

💬

New Comment Sort

Sets the suggested sort to "New" automatically so the live post comment section behaves like a real-time stream chat.

🚀

Rate-Limit Protection

Uses Redis caching to keep status checks fast, lightweight, and safe from Twitch API rate limits.

🛠️

One-Click Mod Reset

Restart the status checker or clear the cache instantly using a custom shortcut directly in your community's mod tools.

How It Works

  1. 1
    Install the app on your subreddit from the Reddit Developer Platform. No server, no hosting, no code.
  2. 2
    Connect your channels — Twitch, YouTube, and/or Kick — by entering your API keys in Mod Tools → Apps → live-sticky → Settings. Takes 2 minutes.
  3. 3
    Go live on any platform. Within 2 minutes, LiveSticky pins a live post and lights up the dashboard automatically — flaired, sorted by New, with a pinned mod comment.
  4. 4
    Just stream. Viewer counts, uptime, and category stay current without you lifting a finger. Your sidebar widget updates too.
  5. 5
    End the stream. LiveSticky waits 6 minutes, then archives the post with VOD links, compiles your top 5 Twitch clips into a highlights post, locks it, and unpins cleanly.
