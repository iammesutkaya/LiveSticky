Moderator Guide & Actions

How to manage LiveSticky directly from your subreddit using built-in mod commands.

Moderator Menu Items

LiveSticky registers custom moderator commands that you can run directly from your community's Mod Menu feed:

Menu ItemDescription & Action
Create LiveSticky Dashboard Creates (or replaces) the pinned interactive dashboard custom post. If you've updated your stream cards or channels, run this to force-refresh the dashboard container.
Restart LiveSticky Flushes cached stream status values from Redis and forces an immediate check. Ideal for validating new Client IDs or API keys immediately without waiting for the next 2-minute poll.
Refresh Profile Images Clears cached avatar image URLs and stream banners. If you or the creator updated their Twitch or YouTube channel profile picture, run this to sync it to the dashboard immediately.
Get Default LiveSticky Templates Opens the Templates & Placeholders reference page directly from the app so you can copy and tweak default post texts.

How to Access Mod Tools

To run any of the actions above, ensure you are logged in with moderator permissions on your subreddit:

  1. 1
    Navigate to your subreddit's home feed (e.g. r/yourcommunity) in the official Reddit mobile app or desktop browser.
  2. 2
    Click the **Mod Tools** shield icon or the overflow menu (three dots button ...) near the top of the feed page.
  3. 3
    Scroll to the **Apps** or **Mod Commands** submenu, and click your desired action. The app will immediately trigger the action and show a confirmation toast notification.
