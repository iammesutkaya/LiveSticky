Configuration Reference

A complete reference of all settings and configuration options available in LiveSticky.

All of these settings live under Mod Tools ➔ Apps ➔ live-sticky ➔ Settings. For step-by-step instructions on generating API credentials, see the Setup Guide.

Looking for post layout variables or default copy-paste text templates? Visit the Templates & Placeholders page. Looking for moderator commands? Check out the Moderator Guide.

App Settings

Per-community settings: The API credential fields below are entered by each subreddit's moderators and used only for that community. Because Devvit only encrypts app-wide secrets (not per-subreddit settings), these values are visible to the moderators of your subreddit in the settings form. Treat them like any shared moderator credential, and rotate them if your mod team changes.
Setting NameTypeDescription
⚙️ Custom Post DashboardBooleanPowers a persistent interactive dashboard post.
⚙️ Dashboard Post HeightSelectSelect the height of your interactive dashboard post. Options: Compact (320px) or Tall (512px). Default: Compact (320px).
⚙️ Sidebar WidgetBooleanCreates and automatically updates a "Stream Status" text widget in your community sidebar.
⚙️ Suggested Comment SortSelectSets default comment sort for live threads (New, Live, Q&A).
⚙️ Offline PostBooleanRecycles a single permanent pinned post when offline to announce news and useful links. The post is unpinned when live and pinned again when offline. Because it is recycled, users are never notified of a new post after creation.
⚙️ Live PostBooleanAutomatically creates and pins a standard text post when the stream goes live.
⚙️ Hide Live Post from Feed when OfflineBooleanMod action: Hides the live post from the community feed when offline. It remains accessible via direct links or comment histories without cluttering the feed.
⚙️ Delete Live Post when OfflineBooleanDeletes the live post and all its comments when the stream ends.
⚙️ Lock Live Thread when OfflineBooleanLocks the live thread post comments when the stream ends so no new comments can be added. (Default: Off)
⚙️ Disconnect Grace Period (Minutes)NumberMinutes to wait before concluding the live post (prevents duplicates during crashes).
⚙️ Streamer TimezoneSelectSelect your local timezone for {date} template variables in post titles & body (covers 27 major global regions). Defaults to UTC.
⚙️ Stream Highlights PostBooleanAutomatically posts a compilation of top Twitch clips generated during the stream when it ends.
⚙️ Sticky Highlights PostBooleanPins the clip compilation post so it stays at the top of the subreddit. It is re-pinned after each stream in case it slipped. Requires Stream Highlights Post.
⚙️ Reuse Single Highlights PostBooleanRecycles a single permanent clips post after each stream instead of creating a new post every time. When off (default), a new highlights post is created for each stream session.
⚙️ Monthly Top 20 Clips PostBooleanPosts a compilation of the top 20 most-watched Twitch clips from the previous calendar month. Use the day/hour settings to choose when it drops.
⚙️ Monthly Post - Schedule DaySelectSelect when to publish the monthly top-20 compilation post: Start of new month (1st), Middle of month (15th), or End of month (Last day). Default: Start of new month.
⚙️ Monthly Post - Publish Time (24h format)StringTime of day in 24h format (e.g. 13:30 or 09:00) in your configured Streamer Timezone. Default: 12:00.
⚙️ Wiki Clip ArchiveBooleanKeeps the full clip history on subreddit wiki pages (one for stream clips, one for monthly top-20) and links to them from the posts. When off, the stream highlights post shows a shorter in-body archive of the last few streams instead. Requires wiki to be enabled on your subreddit. Default: Off.
💊 Dynamic Post Flair UpdatesBooleanPeriodically updates the live post (or dashboard post) flair with active game and live viewers (e.g. 🔴 LIVE: Just Chatting [15.4K]).
💊 Offline User Flair TextStringAssigned to the streamer's user flair when offline.
💊 Live User Flair TextStringAssigned to the streamer's user flair when live.
💊 Live Post Flair Template IDStringThe UUID of the flair template to apply to the live post (from Mod Tools ➔ Look and Feel ➔ Post Flair).
💊 Highlights Post Flair Template IDStringThe UUID of the flair template to apply to the stream highlights post (from Mod Tools ➔ Look and Feel ➔ Post Flair).
👑 Primary PlatformSelectThis platform will always appear at the top of the multistream dashboard.
👑 Avatar Image URLStringOverride your profile picture with a DIRECT Reddit image link (i.redd.it/…). Upload an image to Reddit, then copy its direct link. Leave blank to auto-fetch from your primary platform.
📖 Platform API Setup GuideStringFollow the step-by-step guide to generate API credentials for the platforms below: https://livesticky.com/setup
🟪 Twitch Channel NameStringTwitch channel to monitor.
🟪 Twitch Client IDStringRequired for Twitch.
🟪 Twitch Client SecretStringRequired for Twitch.
🟥 YouTube Channel Name / HandleStringYouTube channel to monitor.
🟥 YouTube API KeyStringRequired for YouTube.
🟩 Kick Channel NameStringKick channel to monitor.
🟩 Kick Client IDStringRequired for Kick.
🟩 Kick Client SecretStringRequired for Kick.
📖 Templates & Placeholders ReferenceStringCopy and paste templates for the text fields below from the LiveSticky website: https://livesticky.com/customization
📺 Dashboard Post TitleStringTitle for the dashboard post.
😴 Offline Post TitleStringTitle for the offline post.
😴 Offline Post BodyParagraphBody for the offline post.
😴 Offline Post Footer TextParagraphAppended to the bottom of the offline post.
😴 Offline Sidebar Widget TextParagraphBody for the offline sidebar widget.
😴 Offline Sidebar Widget Footer TextParagraphAppended to the bottom of the offline sidebar widget.
🔴 Live Post TitleStringTitle for the live post.
🔴 Live Post BodyParagraphBody for the live post.
🔴 Live Post Footer TextParagraphAppended to the bottom of the live post.
🔴 Auto-Pinned Comment TextParagraphAutomatically posts and pins a mod comment inside the live post.
🔴 Live Sidebar Widget TextParagraphBody for the live sidebar widget.
🔴 Live Sidebar Widget Footer TextParagraphAppended to the bottom of the live sidebar widget.
🎬 Concluding Post BodyParagraphBody for the concluding post.
🎬 Concluding Post Footer TextParagraphAppended to the bottom of the concluding post.
🎬 Highlights Post TitleStringTitle for the stream highlights post. Supports {stream_display_name}, {stream_title}, and {date}. Note: {date} is automatically ignored when "Reuse Single Highlights Post" is enabled so the master thread title stays timeless.
🎬 Highlights Post Header TextParagraphIntro shown at the top of the clip compilation post, above the newest stream's clips.
🎬 Highlights Post Footer TextParagraphAppended to the bottom of the clip compilation post.
🏆 Monthly Top 20 Post TitleStringTitle for the monthly top-20 clips post. Supports {month} and {stream_display_name}.
🏆 Monthly Top 20 Header TextParagraphHeader for the monthly top-20 clips post. Supports {month}.
🏆 Monthly Top 20 Footer TextParagraphAppended to the bottom of the monthly top-20 clips post.
📝 Internal Moderator NotesParagraphUse this space as a scratchpad for your mod team to document API key owners, custom flair IDs, or temporary configuration changes. LiveSticky ignores this field.

Once the Custom Post Dashboard is enabled, create the post from Mod Tools ➔ the Create LiveSticky Dashboard menu item. Running it again replaces the existing dashboard rather than creating a duplicate.
